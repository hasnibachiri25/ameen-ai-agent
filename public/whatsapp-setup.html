دليل خطوة بخطوة لإعداد Meta Cloud API وربط خادم Node.js مع واتساب.

يتيح لك هذا التكامل استقبال رسائل العملاء على رقم الواتساب الخاص بشركة أمين ومعالجتها تلقائياً عبر الذكاء الاصطناعي (مساعد أمين الذكي)، مع حفظ الطلبات (Leads) مباشرة في قاعدة بيانات النظام.

1

إعداد حساب Meta for Developers

    قم بزيارة موقع مطوري ميتا وسجل الدخول بحسابك. إنشاء تطبيق جديد (Create App) واختيار نوع التطبيق Business. أضف منتج **WhatsApp** إلى تطبيقك وانتقل إلى لوحة تحكم WhatsApp Setup للحصول على رمز التوثيق المؤقت أو الدائم (Permanent Access Token).
2

إعداد Webhook في الخادم

لكي يستقبل خادم Node.js الخاص بك الرسائل من ميتا، تحتاج إلى إضافة مسار Webhook في ملف server.js بالشكل التالي: 

// WhatsApp Webhook Verification
app.get('/webhook', (req, res) => {
  const VERIFY_TOKEN = process.env.WHATSAPP_VERIFY_TOKEN || 'ameen_secure_token';
  const mode = req.query['hub.mode'];
  const token = req.query['hub.verify_token'];
  const challenge = req.query['hub.challenge'];

  if (mode === 'and' && token === VERIFY_TOKEN) {
    res.status(200).send(challenge);
  } else {
    res.sendStatus(403);
  }
});

// WhatsApp Incoming Messages
app.post('/webhook', async (req, res) => {
  // استقبال الرسالة ومعالجتها عبر OpenAI وتحويلها للعميل عبر WhatsApp Cloud API
  res.sendStatus(200);
});
3

نشر التطبيق على السحابة (Railway أو Render)

بما أن Meta Webhook يتطلب رابط HTTPS عام، يمكنك نشر هذا المشروع على Railway أو Render خلال دقائق باستخدام ملف Dockerfile المرفق في المشروع. بعد نشر التطبيق والحصول على الرابط العام (مثلاً: https://your-app.up.railway.app/webhook)، قم بوضع هذا الرابط في لوحة تحكم Meta ومعه رمز التحقق.
