# مساعد أمين الذكي (Ameen Sales AI Agent) 🇴🇲

تطبيق مبيعات ذكي متكامل مصمم خصيصاً لشركة **أمين (Regal Insurance Management Services LLC)** لتوسيع مبيعات التأمين وخدمة العملاء في سلطنة عُمان.

## مميزات المشروع
1. **مساعد ذكي مدعوم بالذكاء الاصطناعي (OpenAI GPT-4o):**
   - يجيب بدقة على جميع استفسارات العملاء حول التأمين في عُمان (تأمين السيارات، التأمين الصحي "ضماني"، تأمين الحياة، المنازل، السفر).
   - مزود بكافة معلومات شركة أمين وشركائها (OQIC، Liva، GIG، وغيرها).
   - يوجه العملاء لطلب عروض الأسعار وحجز المواعيد ورقم الواتساب الرسمي (`+968 76888817`).
2. **واجهة دردشة عصرية بتصميم WhatsApp:**
   - ألوان الهوية البصرية لأمين (أزرق داكن `#0A1F44` وأزرق فاتح `#4A90D9`).
   - تخطيط عربي بالكامل (RTL) مع أزرار ردود سريعة ونموذج طلب عرض سعر (Lead Capture Modal).
3. **لوحة تحكم الإدارة (Admin Dashboard):**
   - متابعة جميع طلبات العملاء المحتملين (Leads) مع تفاصيل الاسم، الهاتف، نوع التأمين، والملاحظات.
   - إحصائيات فورية وإمكانية التواصل السريع مع العملاء عبر الواتساب أو الاتصال المباشر.
4. **دليل ربط واتساب (WhatsApp Business API Guide):**
   - خطوات مفصلة لربط النظام مع Meta Cloud API.

## متطلبات التشغيل المحلي
- Node.js (الإصدار 18 أو أحدث)
- مفتاح OpenAI API Key

### خطوات التثبيت والتشغيل:
1. فك ضغط المشروع أو الانتقال للمجلد:
   ```bash
   cd ameen-ai-agent
   ```
2. تثبيت الحزم المطلوبة:
   ```bash
   npm install
   ```
3. إنشاء ملف البيئة `.env` بناءً على `.env.example`:
   ```bash
   cp .env.example .env
   ```
   ثم قم بتعديل ملف `.env` وإضافة مفتاح OpenAI الخاص بك:
   ```env
   PORT=3000
   OPENAI_API_KEY=sk-...
   ```
4. تشغيل الخادم:
   ```bash
   npm start
   ```
5. افتح المتصفح على: `http://localhost:3000`
   - واجهة المساعد الذكي: `http://localhost:3000/`
   - لوحة تحكم الإدارة: `http://localhost:3000/admin`
   - دليل ربط الواتساب: `http://localhost:3000/whatsapp-setup`

## تعليمات النشر على المنصات السحابية (Deployment)

### 1. النشر على Railway
1. أنشئ حساباً على [Railway](https://railway.app).
2. أنشئ مشروعاً جديداً (New Project) واختيار **Deploy from GitHub repo** أو رفع مجلد المشروع مباشرة.
3. أضف متغيرات البيئة (Environment Variables):
   - `OPENAI_API_KEY`: مفتاح OpenAI الخاص بك.
   - `PORT`: 3000 (أو اتركه لتحديده تلقائياً بواسطة Railway).
4. سيقوم Railway ببناء التطبيق تلقائياً باستخدام ملف `Dockerfile` المرفق وإعطائك رابط عام (Domain).

### 2. النشر على Render
1. انضم إلى [Render](https://render.com).
2. أنشئ **New Web Service** واربط المستودع.
3. حدد البيئة: **Docker**.
4. أضف متغيرات البيئة في لوحة التحكم (`OPENAI_API_KEY`).
5. اضغط **Create Web Service**.

### 3. النشر على خادم خاص (VPS / Ubuntu)
1. قم بتثبيت Node.js و Docker على الخادم.
2. استسخف أو انسخ ملفات المشروع إلى الخادم.
3. أنشئ ملف `.env` بالقيم المطلوبة.
4. استخدم PM2 لتشغيل التطبيق بشكل مستدام:
   ```bash
   npm install -g pm2
   pm2 start server.js --name "ameen-ai-agent"
   pm2 startup
   pm2 save
   ```
5. يمكنك استخدام Nginx كـ Reverse Proxy أمام منفذ 3000 وتفعيل شهادة SSL (Let's Encrypt).
